# If you want to make it a desktop app:  
(You need to install first _pyinstaller_ , you can easily install it with the __pip install pyinstaller__ command)  

Open a terminal in the folder and tape: <br/>
  __pyinstaller --onefile --windowed --icon=icon.ico <file_name.py>__  <br/>

--onefile: generate an unique .exe file  <br/>
--windowed: avoid the launch of the terminal  <br/>
--icon=icon.ico : icon.ico is your ico file for your .exe file  <br/>

Enjoy
